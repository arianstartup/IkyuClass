# IkyuClass - پلتفرم جامع آموزشی، تحقیقاتی و فروشگاهی

**IkyuClass** یک پلتفرم مدرن و جامع است که با هدف ارائه خدمات متنوع آموزشی، تحقیقاتی، فروشگاهی و امکان رزرو معلم برای کاربران فارسی‌زبان طراحی شده است. این پلتفرم با الهام از شخصیت محبوب "ایکیوسان"، نماد هوش و خلاقیت، به دنبال ساده‌سازی فرآیندهای یادگیری و دسترسی به منابع آموزشی با رویکردی ترکیبی از تعامل انسانی و هوش مصنوعی است.

## قابلیت‌های اصلی

*   **سامانه آموزشی و تحقیقاتی:**
    *   ثبت‌نام دانش‌آموز، دانشجو و معلم با پروفایل کامل.
    *   امکان سفارش تحقیق با موضوع دلخواه و دریافت محتوای علمی استاندارد (با کمک AI).
    *   سیستم رزرو معلم به صورت آنلاین یا حضوری با تقویم زمانی و پرداخت آنلاین.
    *   سیستم امتیازدهی و نظردهی برای معلمان.
*   **فروشگاه لوازم‌التحریر:**
    *   فروشگاه با دسته‌بندی محصولات، فیلتر، سبد خرید و پرداخت آنلاین.
    *   امکان ارائه پک‌های تخفیف‌دار محصولات.
*   **پنل مدیریت پیشرفته:**
    *   داشبورد با آمار و نمودارهای کلیدی.
    *   مدیریت کاربران (معلمان، دانش‌آموزان).
    *   مدیریت محصولات و پک‌های تخفیف‌دار فروشگاه.
    *   مدیریت سفارش‌های فروشگاه.
    *   مدیریت سفارش‌های تحقیق (آغاز تولید محتوا).
    *   تنظیمات یکپارچه‌سازی (درگاه پرداخت، پنل پیامک، سرویس AI).
*   **سیستم احراز هویت و نقش‌ها:**
    *   ثبت‌نام با تایید شماره تلفن (OTP).
    *   ورود با ایمیل و پسورد.
    *   مدیریت نقش‌های کاربر (ادمین، معلم، دانش‌آموز) با استفاده از Firebase Custom Claims.
    *   کنترل دسترسی به بخش‌های مختلف بر اساس نقش.

*   **Frontend:**
    *   Next.js (React Framework)
    *   TypeScript
    *   Tailwind CSS
    *   Firebase Client SDK (Authentication, Firestore)
    *   React Hook Form (مدیریت فرم‌ها)
    *   Zod (اعتبارسنجی داده‌ها)
    *   Chart.js (نمایش نمودارها)
    *   `react-chartjs-2`
    *   `@heroicons/react` (آیکون‌ها)
*   **Backend:**
    *   Node.js
    *   Express.js
    *   Firebase Admin SDK (Authentication, Firestore, Storage)
    *   bcrypt (هش کردن پسورد و OTP)
*   **پایگاه داده:**
    *   Cloud Firestore (NoSQL Database)
*   **فضای ذخیره‌سازی فایل:**
    *   Firebase Storage
*   **سرویس‌های شخص ثالث (شبیه‌سازی شده در توسعه):**

## راهنمای راه‌اندازی و اجرا به صورت محلی (Local Setup)

### ۱. دریافت کدها

ابتدا ریپازیتوری پروژه را از گیت‌هاب کلون کنید:
```bash
git clone <URL_ریپازیتوری_شما>
cd <نام_پوشه_پروژه>
```

### ۲. پیکربندی Backend

1.  وارد پوشه `backend` شوید:
    ```bash
    cd backend
    ```
2.  وابستگی‌ها را نصب کنید:
    ```bash
    npm install
    ```
3.  **پیکربندی Firebase Admin:**
    *   به [کنسول Firebase](https://console.firebase.google.com/) بروید و یک پروژه جدید ایجاد کنید (یا از پروژه موجود استفاده نمایید).
    *   از بخش "Project settings" > "Service accounts"، یک کلید خصوصی جدید (private key) برای حساب سرویس با فرمت JSON دانلود کنید.
    *   فایل دانلود شده را به `serviceAccountKey.json` تغییر نام داده و آن را در ریشه پوشه `backend` قرار دهید. **مهم:** این فایل حاوی اطلاعات حساس است و نباید در ریپازیتوری‌های عمومی commit شود. (فایل `backend/.gitignore` باید شامل `serviceAccountKey.json` باشد).
    *   در کنسول Firebase، سرویس‌های زیر را برای پروژه خود فعال کنید:
        *   **Firestore Database:** در حالت Native Mode ایجاد کنید. قوانین امنیتی اولیه را تنظیم کنید (برای شروع تست می‌توانید قوانین بازتری قرار دهید اما برای محیط پروداکشن باید آن‌ها را محدود کنید).
        *   **Firebase Authentication:** متدهای ورود "Email/Password" و "Phone" را فعال کنید.
        *   **Firebase Storage:** یک سطل (bucket) پیش‌فرض ایجاد کنید. قوانین امنیتی اولیه را تنظیم نمایید.
4.  **پیکربندی متغیرهای محیطی Backend:**
    *   فایل `backend/.env.example` را به `backend/.env` کپی کنید.
    *   مقادیر لازم را در فایل `.env` وارد نمایید:
        *   `ADMIN_SECRET_KEY`: یک کلید مخفی برای دسترسی اولیه به APIهای ادمین از طریق هدر یا query param (این یک روش موقت و ناامن برای توسعه است و باید با سیستم احراز هویت واقعی ادمین مبتنی بر توکن جایگزین شود).
        *   `ZARINPAL_MERCHANT_ID`, `ZARINPAL_SANDBOX_MODE`: برای درگاه پرداخت زرین‌پال.
        *   `SIMULATED_SMS_API_KEY`, `SIMULATED_SMS_SENDER_NUMBER`: برای سرویس پیامک شبیه‌سازی شده.
        *   `GEMINI_API_KEY`: برای سرویس هوش مصنوعی شبیه‌سازی شده.
        *   `FRONTEND_URL`: آدرس کامل Frontend (مثلاً `http://localhost:3000`) برای استفاده در redirectهای پرداخت.
        *   `CALLBACK_BASE_URL`: آدرس پایه Backend برای callbackهای درگاه پرداخت (مثلاً `http://localhost:3001` اگر سرور بک‌اند روی این پورت است).
5.  اجرای سرور Backend:
    ```bash
    npm run dev
    ```
    سرور Backend معمولاً روی پورت `3001` (یا پورتی که در فایل `.env` به عنوان `PORT` تنظیم کرده‌اید) اجرا خواهد شد.

### ۳. پیکربندی Frontend

1.  در یک ترمینال جدید، وارد پوشه `frontend` شوید:
    ```bash
    cd ../frontend
    ```
    (اگر از ریشه پروژه حرکت می‌کنید)
2.  وابستگی‌ها را نصب کنید:
    ```bash
    npm install
    ```
3.  **پیکربندی Firebase Client SDK:**
    *   در کنسول Firebase، به بخش "Project settings" بروید. در قسمت "Your apps"، یک وب اپلیکیشن جدید اضافه کنید (اگر قبلاً ایجاد نشده).
    *   اطلاعات پیکربندی Firebase (شامل `apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`) را کپی کنید.
    *   فایل `frontend/.env.local.example` را به `frontend/.env.local` کپی کنید.
    *   مقادیر کپی شده از کنسول Firebase را در فایل `.env.local` برای متغیرهای `NEXT_PUBLIC_FIREBASE_*` مربوطه قرار دهید.
4.  اجرای سرور Frontend:
    ```bash
    npm run dev
    ```
    سرور Frontend معمولاً روی پورت `3000` اجرا خواهد شد.

### ۴. دسترسی به برنامه

مرورگر وب خود را باز کرده و به آدرس `http://localhost:3000` بروید تا وب‌سایت را مشاهده کنید.

## راهنمای استفاده از پلتفرم (خلاصه)

### ثبت‌نام و ورود
*   کاربران جدید می‌توانند با استفاده از شماره تلفن و دریافت کد تایید (OTP) ثبت‌نام کنند (برای معلم و دانش‌آموز).
*   پس از ثبت‌نام، کاربران می‌توانند با ایمیل و پسوردی که در زمان ثبت‌نام تعیین کرده‌اند، وارد سیستم شوند.

### پنل کاربری دانش‌آموز/دانشجو
*   **سفارش تحقیق:** ثبت درخواست برای تحقیق. پس از آماده‌سازی توسط ادمین (تولید محتوا با AI) و پرداخت، امکان دانلود فایل تحقیق.
*   **رزرو معلم:** مشاهده لیست معلمان، برنامه‌های زمانی، نظرات، و رزرو جلسه. امکان پرداخت و مشاهده رزروهای قبلی. امکان لغو رزرو.
*   **فروشگاه:** خرید محصولات و پک‌ها. (فرآیند تسویه حساب پیاده‌سازی شده).
*   **امتیازدهی:** ثبت نظر و امتیاز برای معلمان پس از اتمام جلسات رزرو شده.

### پنل کاربری معلم
*   (نیاز به ایجاد UI اختصاصی دارد) تکمیل پروفایل، تعیین برنامه زمانی.
*   مشاهده کلاس‌های رزرو شده و اطلاعات دانش‌آموزان (از طریق پنل ادمین فعلاً قابل مشاهده است). امکان لغو جلسه.

### پنل مدیریت (Admin)
*   **دسترسی:** از طریق مسیر `/admin`.
    *   **برای ورود به عنوان ادمین:**
        1.  یک کاربر عادی (مثلاً معلم یا دانش‌آموز) را از طریق فرم‌های ثبت‌نام سایت ایجاد کنید (با شماره موبایل و OTP، سپس ایمیل و پسورد).
        2.  **روش اول (دستی در Firestore/Auth Console - برای اولین ادمین):**
            *   در Firestore، به کالکشن `users` بروید و داکیومنت مربوط به آن کاربر را پیدا کنید. فیلد `role` آن را به `admin` تغییر دهید.
            *   در Firebase Authentication Console، کاربر مربوطه را پیدا کنید. به بخش "Custom Claims" (معمولاً با کلیک روی سه نقطه کنار کاربر و انتخاب "Edit user" یا مشابه) بروید و یک claim جدید با کلید `role` و مقدار `admin` (به صورت رشته) اضافه کنید.
        3.  **روش دوم (با API - اگر ادمین دیگری از قبل وجود دارد):**
            *   از API `PUT /api/admin/users/:userId/role` که قبلاً ایجاد شده، با استفاده از توکن یک ادمین موجود، نقش کاربر جدید را به `admin` تغییر دهید.
        4.  با ایمیل و پسورد همان کاربر از طریق صفحه `/login` در سایت وارد شوید. اکنون باید دسترسی ادمین به مسیر `/admin` داشته باشید.
*   **داشبورد:** مشاهده آمار کلی پلتفرم با نمودار.
*   **مدیریت کاربران:** مشاهده لیست کاربران (معلمان، دانش‌آموزان پراکسی) با فیلتر و جستجوی ساده. امکان تغییر نقش کاربر.
*   **مدیریت محصولات:** افزودن، ویرایش و حذف محصولات و پک‌های تخفیف‌دار فروشگاه.
*   **مدیریت سفارش تحقیق:** امکان آغاز فرآیند تولید محتوای تحقیق برای سفارش‌های ثبت شده.
*   **تنظیمات یکپارچه‌سازی:** وارد کردن و ذخیره کلیدهای API برای درگاه پرداخت زرین‌پال، پنل پیامک (شبیه‌سازی شده) و سرویس هوش مصنوعی Gemini (شبیه‌سازی شده).

## ساختار پروژه (کلی)

*   **`/backend`**: شامل کدهای مربوط به سرور Node.js/Express، تمام APIها، مدل‌های داده، کنترلرها، و ارتباط با Firebase Admin SDK.
*   **`/frontend`**: شامل کدهای مربوط به رابط کاربری Next.js/React، صفحات، کامپوننت‌ها، مدیریت وضعیت، و ارتباط با Firebase Client SDK و APIهای Backend.

## راهنمای استقرار روی سرور (کلیات)

### Frontend (Next.js)
*   **پیشنهاد:** Vercel، Netlify، Firebase Hosting.
*   **مراحل عمومی:** اتصال ریپازیتوری گیت، تنظیم دستور ساخت (`npm run build`)، تنظیم متغیرهای محیطی پروداکشن (`NEXT_PUBLIC_FIREBASE_*`).

### Backend (Node.js/Express)
*   **پیشنهاد:** Render, Fly.io, یا سرور مجازی (VPS).
*   **مراحل عمومی (PaaS):** اتصال گیت، تعریف start command، تنظیم متغیرهای محیطی پروداکشن، مدیریت امن `serviceAccountKey.json`.
*   **مراحل عمومی (VPS):** راه‌اندازی سرور، نصب Node.js/PM2، کپی کدها، نصب وابستگی‌ها، تنظیم متغیرهای محیطی، اجرای با PM2، پیکربندی reverse proxy (Nginx/Apache) و SSL.
*   **Serverless (Firebase Cloud Functions):** انتقال APIهای Express به Cloud Functions برای مدیریت آسان‌تر و مقیاس‌پذیری.
